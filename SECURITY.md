# Security Policy — `lume.tmLanguage`

## Supported Versions

| Version | Supported | Notes |
| :--- | :---: | :--- |
| `1.1.x` | Yes | Hardened against catastrophic regex backtracking (`ReDoS`) in all TextMate patterns |

## Reporting a Vulnerability

Please report any regular-expression backtracking (`ReDoS`) or grammar injection issue via the main **[OmegaSoftDLL/Lume Security Advisories](https://github.com/OmegaSoftDLL/Lume/security/advisories)**.
