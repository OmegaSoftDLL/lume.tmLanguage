  Contributing &amp; Grammar Verification
</h1>
<br clear="left"/>

1. All files in `lume.tmLanguage` use **pure LF (`\n`)** line endings and **zero tabs**.
2. Validate `syntaxes/Lume.tmLanguage.json` as strict JSON before committing.
3. Inspect token scopes in VS Code using `Developer: Inspect Editor Tokens and Scopes`.
